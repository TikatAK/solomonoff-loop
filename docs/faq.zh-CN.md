# 常见问题（FAQ）

> 最尖锐的反对意见与回答。如果某个问题问岔了，回答会直接指出。

---

### Q1.「你没有逃离评估器瓶颈——只是把它搬进了合成和规范里。」

部分成立，但那次搬移是**严格改进**，不是搪塞。

- 在规范层，一个正确规范能认证无限多程序，且规范远更可压缩、可检查。信任面从「所有生成的 token」缩到「一小撮可审计的规范」。这是可达到的最佳上界——这正是人类在做的事（我们审计公理与法律，而非每一次推理）。
- 锚点是**保留现实上的预测误差**，不是自洽性。即便是一个规范，也是一个带可测量外部成绩单的可证伪预测。
- 那个承重的不对称性依然成立：合成错误被*检测并丢弃*；评估器错误被*静默吸收*。把弱点从评估器（不可恢复）搬到合成器（可自举），正是全部要点。

### Q2.「谁来验证验证器？」

**元循环。** 规范本身就是可证伪的程序，以同样方式递归接地。一个规范能存活，仅当其认证的程序持续预测现实。不存在无限层的验证者塔——存在一个在「现实的保留样本」处触底的塔，而那是唯一不可伪造的裁判。

### Q3.「这不就是程序合成 / RLVR / 蒸馏，包装了一下？」

它*使用*这三者，但论断是关于**循环**的，而非任何单一组件。

- **程序合成**是一个步骤，不是循环；单独它没有「累积已验证知识」的概念。
- **RLVR**（可验证奖励）有效但局限于可验证领域，且不保留一个增长的、可读的自我模型。
- **蒸馏**若不与调用配对（不变量 2），就会丢失尾部。

新颖的组合是：*一个按描述长度排序的、经机械验证的、可执行的程序层，它同时充当接地、自我模型、课程与冻结对照。* 没有任何单一的现有组件是这个。

### Q4.「这怎么扩展到写作、对话、品味——那些没有执行器的领域？」

「可验证性」是*命题形式*的性质，而非领域的性质。一个开放域能力通常可以被重述为一个**带有现实结果变量的预测任务**：「好文笔」变成「预测人类给哪段文字打更高分的程序」，并针对保留的*人类判断*测试。

两个诚实提醒：(1) 优化一个代理程序可能偏离真实质量（Goodhart），且该漂移通过结果变量的选择重新进入；(2) 对*零*可观测结果的领域，没有框架可行——包括人类实践。我们陈述这个边界，而非掩盖它。

### Q5.「算法概率（CTM/BDM）不是不可计算吗？」

Kolmogorov 复杂度 `K(x)` 在一般情况下确实不可计算。CTM/BDM 是对短字符串的*可计算近似*，且它们能捕捉压缩器漏掉的结构（如 `101010…`）。实用阶梯是：**MDL / 符号回归复杂度**（PySR 已在最小化）→ **gzip / NCD**（可扩展的粗略下界）→ **CTM/BDM**（严谨、小规模）→ **Lean/Coq 证明项**（严格、窄）。我们用契合规模的梯级；玩具 DSL 正是 CTM/BDM 可计算的区间。

### Q6.「这不就是 harness 工程（Lilian Weng / Darwin Gödel Machine）吗？」

不是——而且差异正是承重的那一个。Harness 工程重写的是**冻结模型**周围的*脚手架*；模型权重不变，也没有任何东西累积进模型。Solomonoff Loop 重写的是一个*不断增长的程序层*，并把它蒸馏回模型（不变量 2 的「蒸馏」分支）。这正是 SPEE 所点名的那个缺失的中间环节——没有权重内化的 test-time 提取，只是循环的一半。

### Q7.「安全呢？」

真实存在，并作为一道闸门而非事后补充处理。路线图中的安全审查要求：铁砧保持非 LLM 并位于它所评分的循环之外；循环不能修改自己的评估通道；只追加日志；任何触及规范层的改动都需人工批准。危险不在于「改进」——而在于一个智能体编辑自己的评估器，这会让「改进」与「改分」无法区分。本设计特意把评估器*排除*在循环的写权限之外。

### Q8.「我怎么知道所报告的改进是真的，而非幻影提升？」

晶体在**构造上**就是冻结对照。每个程序都是一条可检查断言；退化 = 一个以前通过的程序现在失败了。审计协议（experiment-design §7）还进一步要求：保留输入上的精确匹配、转移级报告、bootstrap 置信区间、FDR 控制、以及绝不重复使用保留数据。改进可由第三方重跑铁砧来审计。

### Q9.「诚实地讲，这里到底*新*在哪？」

不在组件。在**配置**——具体是三个此前没有任何系统同时具备的东西：

1. 一个*机械、非 LLM* 的验证器，让唯一不可恢复的失败模式（弱评估器）在结构上不可能发生。
2. 一个*按描述长度排序*的程序层，它同时是反坍缩接地（2601.05280 的逃生）、可内省自我模型（2607.04277 缺失的原语）、以及课程。
3. 一个*递归规范层*（元循环），让评估器本身共同进化——正是 2025–26 前沿明确点名为未解决的空白。

这个配置是否真的会复利，恰恰是那个实验要证伪的问题。
