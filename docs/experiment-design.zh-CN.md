# 实验设计

> 这个框架是一个假设。本文档是那个会**证伪**它的实验。它的职责不是产出一个讨喜的数字——而是搞清楚晶体是否在「验证并丢弃」之外做了任何真实的工作。

---

## 1. 证伪判据

**零假设（H₀）：** 晶体没有任何增益。一个「验证程序然后*扔掉*它们」（只验证、不保留）的循环，与保留晶体的循环一样好。

**框架只有在满足以下全部条件时才算存活**（完整循环 = 保留晶体）：

1. 尾部准确率随轮次**单调提升**（在稀有/对抗输入上测量），*且*
2. 每一轮的**熵健康**（不坍缩），*且*
3. 晶体的**总描述长度缩小**，*且*
4. **击败消融 D**（只验证不保留），且超出 bootstrap 置信区间。

如果完整循环只*打平*消融 D，那么这个框架就是在搬移坍缩而非逃离它——诚实的结论是：它不成立。

---

## 2. 玩具 DSL

程序要小到能可靠合成，又要丰富到能检验「压缩保住尾部」这个论断。DSL：

```
value   ::= int | bool | list<int> | str
expr    ::= 字面量
          | 变量
          | expr + expr | expr - expr | expr * expr | expr // expr | expr % expr
          | expr == expr | expr != expr | expr < expr | expr <= expr | ...
          | and(expr, expr) | or(expr, expr) | not(expr)
          | if expr then expr else expr
          | loop n over acc  （有界迭代，n ≤ 20）
          | recurse （有界递归，深度 ≤ 5）
          | append(expr, expr) | index(expr, expr) | length(expr)
          | concat(expr, expr) | substr(expr, expr, expr)
          | map(func, expr) | filter(func, expr)
```

- **约 15–20 个原语**，程序 ≤ **约 30 个 AST 节点**。
- DSL 被刻意做小：这是 **CTM/BDM**（短字符串上的算法概率）仍然可计算、且「描述长度」与「困惑度」的差异最为可见的区间。

---

## 3. 真值现实（P*）

- 从 DSL 中均匀采样 **N = 200 个隐藏程序**。这些就是 **P***——循环必须发现的「现实」。模型*永远看不到 P\* 本身*，只能看到样本。
- 对每个 `P*_i`，生成：
  - **k = 5–20 个训练对** `(x_j, y_j = P*_i(x_j))` —— 对提议者可见。
  - **m = 50 个保留验证对** —— 在合成期间*绝不*展示给模型；只供铁砧使用。
  - **尾部对**：一组保留的*稀有/对抗*输入（极值、空列表、边界情况），专门用于测量尾部准确率。

这个划分就是全部要点：匹配 k 个训练对是*记忆*；匹配 m 个保留对是*泛化*，而它是唯一进入外部信号的地方。

---

## 4. 循环，具体化

```
for 轮次 t in 0..T:
  for 每个处于未解决或可退化状态的目标 i:
    1. 提议      提议者看到 (x_j, y_j)（j=1..k），从 DSL 中采样 B 个候选程序。
    2. 验证      铁砧在 m 个保留输入上执行每个候选。仅保留在全部 m 上精确匹配者。
                 （机械的。）
    3. 排序      在存活者中，保留描述长度最小者
                 L = gzip_len(source) + λ·(AST 节点数)。
                 （λ 是一个小的复杂度惩罚；MDL 是首要替身。）
    4. 结晶      将最短存活者加入晶体。
    5. 接地
       (i)  蒸馏 —— 在从晶体重采样的输入输出上微调提议者，显式包含尾部输入；
       (ii) 调用 —— 让晶体在推理时保持为可调用工具。
    6. 内省（仅阶段 2）提议者可合并/重构/修补晶体程序；
       一个改动仅当仍通过所有 m 个保留验证时才会被接受。
```

实现说明：

- **铁砧**是 DSL 上的普通解释器——不含神经组件。
- **提议者**是一个基础 LLM（如 3B–8B 模型），在程序归纳轨迹上微调；它与任何裁判都**不共享权重**。
- **引导者**是一个提示级过滤器（或一个单独的小 LLM），丢弃「碰巧通过 m 个验证的平凡候选」（如常量程序），并标记那些看起来像「模型写的」而非「现实派生的」规范。

---

## 5. 指标（全部报告 bootstrap 95% 置信区间）

| 指标 | 定义 | 检验什么 |
|---|---|---|
| **尾部准确率** | 在保留的稀有/对抗输入上的准确率 | 压缩是否保住尾部 |
| **熵 / 覆盖率** | 模型输出分布（或候选多样性）的熵 | 循环是否坍缩 |
| **晶体验证准确率** | 保留程序的保留集准确率 | 晶体是否真的泛化 |
| **描述长度** | 晶体的总 `L` | 「改进 = 更短的程序」是否成立 |
| **转移矩阵** | 各目标在轮次间 fail→pass / pass→fail 的计数 | 审计协议（见下） |

---

## 6. 消融实验（这才是证明）

| 消融 | 改变什么 | 若框架正确，预期结果 |
|---|---|---|
| **A. α = 0 自训练** | 无铁砧；模型只在自身输出上训练 | 坍缩 / 熵衰减（复现 2601.05280） |
| **B. LLM 当裁判** | 用第二个 LLM 的评分替代铁砧 | 自我确认循环：过度奖励高置信错误 |
| **C. 困惑度排序** | 用模型自身似然而非描述长度排序候选 | 更差的尾部恢复；偏好「貌似合理但错误」的程序 |
| **D. 无晶体** | 验证程序但*不*保留/蒸馏它们 | **关键对照。** 无复利改进。 |

**决定性检验是 D。** 如果完整循环不击败 D，晶体就是死重，框架应当被放弃。

---

## 7. 审计协议（「幻影提升」的解药）

近期工作（「幻影提升」审计）显示，被报道的自我改进常常是测量伪影：单一贪心解码、均值准确率、以及缺少冻结对照，都会夸大表观增益。本协议被设计为对它们免疫：

1. **构造上就有的冻结对照。** 晶体*本身就是*冻结对照——每个保留程序都是一条可检查断言。退化 = 一个以前通过的程序现在失败了。
2. **仅保留输入上的精确匹配。** 没有裁判、没有软打分、没有 LLM 评分器。程序要么通过，要么不通过。
3. **转移级报告。** 报告*哪些目标*从 fail→pass、哪些从 pass→fail，而非仅报告聚合值。聚合准确率会掩盖「这里进步、那里退化」。
4. **Bootstrap 置信区间 + FDR 控制。** 所有比较都报告 bootstrap 95% 置信区间，并对各目标做错误发现率控制。
5. **绝不重复使用保留数据。** m 个验证对只用一次；任何偷看它们的调参都会使该轮作废。

因此成功判据是**可审计**的：第三方可以在晶体上重跑铁砧，无需信任作者即可确认所报告的准确率。

---

## 8. 成功判据，按序

1. 尾部准确率随轮次单调提升（在置信区间内）。
2. 熵在任意轮次都不衰减。
3. 晶体描述长度缩小。
4. 完整循环击败消融 D（超出 bootstrap 置信区间）。
5. （阶段 2）一个被内省/修补过的晶体仍能验证并改进。

1–4 失败 = 框架被证伪。在 D 上得到一个*零结果*，是**最有价值**的结果：它让整个领域免于在沙子上建造。

---

## 9. 规模与工作量

| | |
|---|---|
| DSL | 约 15–20 个原语，≤ 约 30 个 AST 节点 |
| 真值 | N = 200 个隐藏程序 |
| 模型 | 3B–8B 基础 LLM（提议者）；可选小 LLM（引导者） |
| 算力 | 单 GPU，数天 |
| 工作量 | **1–2 周**（对一位有能力的研究者而言） |

每一个组件——程序合成、DSL 解释、gzip/BDM 排序、蒸馏——今天都已存在。这里没有任何东西需要研究突破；这个实验检验的是这个*组合*是否是突破。
