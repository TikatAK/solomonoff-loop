# 核心机制

> 本文档是 Solomonoff Loop 的思想内核。它精确地陈述问题、给出理论依据、定义循环与五条不变量，并且——同样重要地——标出「已接地」与「推测」之间的边界。

---

## 1. 术语

| 术语 | 含义 |
|---|---|
| **提议者 Proposer** | 从自身隐性知识中合成候选程序的 LLM。 |
| **铁砧 Anvil**（验证器） | *机械*验证器：执行器、证明检查器、或保留数据匹配。**绝不是一个 LLM。** |
| **晶体 Crystal**（程序层） | 不断增长的、已验证的、可执行的、可读的程序库。 |
| **引导者 Guide** | 一个有两份工作的 LLM 角色：反平凡过滤 + 规范接地审计。 |
| **蒸馏 Distillation** | 晶体 → 权重（在晶体重采样的输入输出上微调）。 |
| **接地 Grounding** | 通过让程序在现实上执行而获得的外部信号。 |
| **描述长度 Description length** | `L = L(data|program) + L(program)` —— MDL / 算法概率的选择判据。 |

---

## 2. 核心论断

> 一个显式的、可执行的、按描述长度排序的程序层，能够**同时**充当 **(a)** 阻止坍缩的外部接地、**(b)** 可内省的功能自我模型、**(c)** 不坍缩的课程——并且，构建这样一个层的循环，严格稳定于任何「评估器是学出来的或自我指涉的」自我改进方法。

该论断是**可证伪**的：它的成立与否，取决于晶体是否产生相对「只验证不保留」（实验设计中的消融 D）的可测增益。如果没有，那么这个框架就只是在搬移坍缩，而非逃离它。

---

## 3. 三种失败模式

文献中的每一种自我改进方法，都以三种方式之一失败。这三种本质上是**同一种失败**——一个弱的改进信号——换的三副面具。

### 3.1 自我确认循环

**机制。** 当生成器与评估器共享权重时，它们的偏置会相互关联。2025 年的《Breaking the Self-Confirming Loop》诊断了自奖励 RL 中的这一机制：与置信度耦合的奖励会系统性地过度奖励**高置信度的错误**，于是循环优先强化了模型最确信的那些错误。这是奖励黑客的普遍形态——显式的「戏弄裁判」只是其中的对抗性特例。

**为何致命。** 偏置会逐轮复利。没有自我纠正；循环在构造上就是自我确认的。

**设计的回答。** 不变量 1：铁砧与提议者**零共享权重**，因为它根本不是神经模型。

### 3.2 模型坍缩 / 熵衰减

**机制。** 用自身输出训练自己会丢失分布尾部。Shumailov 等人（《The Curse of Recursion》，Nature 2024）证明即使在近乎理想的条件下这也是不可避免的，由两个复合的误差源驱动（有限采样带来的统计近似误差，以及容量限制带来的函数近似误差）。2026 年的《On the Limits of Self-Improving LLMs》(2601.05280) 将其形式化为一个动力系统：当外部接地比例 α → 0 时，模型均值遵循一个仅以支撑集直径为界的随机游走——这是**漂移**，而不仅仅是丢模态。

**为何致命。** 没有任何实用的自我改进循环承受得起丢失尾部——尾部正是泛化与「意外」所在之处。

**设计的回答。** 不变量 2 与 3：晶体是**重采样器**，不是记忆。一个已验证程序编码了生成机制；重采样它能重现**包括尾部在内的**完整分布。这正是 2601.05280 逃生路线的具体实例化（见 §4）。

### 3.3 多样性坍缩

**机制。** 在共同进化循环中，*提议者*会收敛到「恰好满足奖励」的窄带上。自对弈课程让求解者失去真正的新挑战。新颖性是一种封闭循环会耗尽的消耗性资源。

**为何致命。** 循环在一个不断缩小的任务空间区域里变得极好——一个伪装成进步的局部最优。

**设计的回答。** 不变量 4：引导者的「反平凡」职责正是拒绝「有难度但无价值」的任务，而它的接地审计把课程锚定在现实而非模型的先验上。

## 4. 理论逃生口

两篇 2026 年的论文从不同方向论证：逃离这些失败的路径是**神经符号**的——而且它们收敛到同一个原语。

### 4.1 算法概率保住分布

《On the Limits of Self-Improving LLMs》(2601.05280) 证明：**纯分布式的自训练必然坍缩**，因为它依赖有限样本的经验性质。证明给出的构造性逃生口：**由算法概率引导的程序合成**（编码定理法 CTM、块分解法 BDM）。关键洞察：

> 一个能生成观测数据的极小程序 `p*` 隐含地定义了**整个**分布——包括有限样本看不见的尾部。「学习更简洁、更算法概率化的、能解释数据的程序」是一个不同于「更低困惑度」的目标，而它是那个不会衰减的目标。

### 4.2 可执行符号补上缺失的自我模型

《Self-reference in LLMs: the introspection threshold for RSI》(2607.04277) 论证：持续的递归自我改进需要一个**忠实的功能自我模型**——一个冯·诺依曼式的复杂度阈值。但标准 Transformer 是前馈的，且受限于一致电路类 TC⁰，因此无法读取自己的权重、无法做定点迭代；它们在**结构上**无法做到真正的内省。缺失的原语，是一个可读、可执行的、对系统自身能力的表征——这正是晶体的定义。

综合：**晶体同时是算法概率锚点（§4.1）和功能自我模型（§4.2）。** 这才是那个新颖的组合。两篇论文单独都没有提出这个循环；这个循环才是本工作的贡献。

## 5. 循环

形式化为每轮过程：

```
第 t 轮：
  1. 提议      对每个活跃目标，提议者从 k 个观测样本中合成一批候选程序。
  2. 验证      铁砧在模型从未见过的 m 个保留输入上运行每个候选。失败的候选被丢弃。
               （这是外部信号——它强制泛化，而非记忆。）
  3. 排序      存活的候选按描述长度 L = L(data|program) + L(program) 排序；
               每个目标保留最短者。
  4. 结晶      将存活者加入晶体。
  5. 接地      (i)  蒸馏：在从晶体重采样的输入输出（含尾部输入）上微调提议者；
               (ii) 调用：让晶体在推理时保持可调用。
  6. 内省      提议者读取晶体，可提议合并、重构或打补丁。
               一个改动仅当仍通过所有目标的保留集验证时才会被接受。
```

第 2、3 步，以及第 6 步的接受门，是**机械的**。第 1、5 步，以及第 6 步的提议，是**神经的**。二者之间的边界，就是全部要点所在。

### 为什么第 2 步就是接地

第 2 步是唯一进入新鲜、非自生成信号的地方。针对保留输入的执行**不是**从模型的软分布推导出来的——一个程序要么产生正确的保留输出，要么不产生。这就是坍缩定理中的 α > 0 项，也是循环不漂移的原因。

## 6. 五条不变量（定律）

1. **铁砧永远是机械的，绝不用 LLM。** 执行器、证明检查器、或保留数据匹配。这是反自我确认循环定律。任何一处 LLM 当裁判，都会重新打开失败模式 3.1。

2. **晶体双用途：蒸馏求流畅，调用求尾部。** 蒸馏（不变量 2 的「蒸馏」分支）是模型内化机制*结构*的方式；调用（「调用」分支）是*尾部*在模型有限近似下存活的方式。二者缺一不可；任一单独使用都会失败。

3. **晶体是重采样器，不是记忆。** 反坍缩定律。一个程序是无限接地输入输出流的生成器；重采样它（而非重放有限样本）才是对抗熵衰减的方式。

4. **引导者有两份工作：反平凡 + 规范接地审计。** 反多样性坍缩定律。引导者是唯一处于把关位置的 LLM，而它自己受铁砧成绩单的约束。

5. **选择信号是描述长度，不是模型似然。** 反循环定律。模型自身的困惑度是其自身信念的函数；描述长度是程序可压缩性的函数，与模型无关。

## 7. 元循环（谁来验证验证器）

最尖锐的反对意见是：第 2 步只是把信任边界向上推了一层——**谁写测试？** 如果提议者同时编写程序与测试，那么执行对生成器的*分布*是外部的，但对模型的*关于现实的信念*并非外部。

答案是递归接地：

> **规范本身就是可证伪的程序。** 一个规范能存活，仅当其认证的程序持续预测现实。规范的「成绩单」——「它是否产生能泛化到保留数据的程序？」——是可测量的、外部的。

现实是唯一不可伪造的外部裁判，并且它可以在**任何一个有可观测结果的层级**被调用。这闭合了回溯：不存在无限层的验证者塔；存在一个在「现实的保留样本」处触底的塔。

形式化地，元循环是：

```
元轮次：
  1. 规范是（可能更丰富的）DSL 中的程序。
  2. 一个规范由「它所接纳的程序在保留数据上随时间累积的预测成功率」来评估。
  3. 接纳「能预测现实的程序」的规范得以留存；接纳「过拟合程序」的规范权重衰减。
```

正是这个机制让**评估器本身共同进化**——填补了 2025–26 前沿（CORAL、Aspire、Darwin Gödel Machine）明确点名为未解决的那个空白。

## 8. 为什么这比先前工作更稳定：容错不对称性

设计严格优于自奖励或自对弈的最重要原因，可以表述为一个不对称性：

| 错误类型 | 发生在哪 | 后果 |
|---|---|---|
| 合成错误（提议者写了错的程序） | 第 1 步 | 被铁砧**检测** → 丢弃。代价：浪费一个候选。 |
| 评估器错误（裁判给了错的奖励） | （在自奖励中：裁判处） | 被**静默吸收** → 被强化 → 复利。 |

弱的合成器只会*拖慢*循环（每轮验证通过的程序更少）。弱的评估器会*腐化*循环（坏奖励被强化，偏置复利）。此外，合成质量是*可自举*的——模型通过观察哪些程序验证通过而变强——而坏裁判瓶颈是自我强化的、没有逃生口。

**推论：循环唯一不可恢复的失败模式是评估器，而评估器是机械的。** 这就是为什么设计把全部正确性押在不变量 1 上。

### 晶体是内置的冻结对照

第二个独立的稳定性性质：晶体中的每一个程序都是一条**能力的可检查断言**。退化 = 一个以前验证过的程序现在在保留集上失败了。这是一个构造上就存在的冻结对照——「幻影提升」问题的解药（见 [experiment-design.zh-CN.md](experiment-design.zh-CN.md) 中的审计协议）。改进是**可审计**的，而不仅仅是被报告的。

## 9. 形式化草图

*本节是草图；完整形式化是开放工作。*

**论断（坍缩定理，2601.05280 的转述）。** 设自训练算子更新分布 `Q_{t+1} = T(P'_t) + ε_t`，其中 `P'_t` 是经验样本，`α_t` 是外部数据的比例。若 `α_t → 0`，则模型均值 `μ_t` 遵循 `μ_{t+1} ≈ μ_t + ξ_t`（随机游走），于是 `Var(μ_t)` 线性增长，分布漂离真实。

**论断（晶体的逃生）。** 晶体用*程序诱导的*分布 `P(p*)` 替换经验样本 `P'_t`，其中 `p*` 是与数据一致的最短程序。因为 `p*` 定义了分布的支撑——包括在 `P'_t` 中不可见的尾部——从 `P(p*)` 重采样不会遭受有限样本熵衰减。外部接地项 `α_t` 不是由「更多人类数据」提供的，而是由**针对保留现实的执行**提供的，这是一个取之不尽、不可伪造的源泉。

**开放量。** 「兑换率」——*多少外部接地才足够*——尚未确立。没有人测出循环退化所需的最小 α 阈值。这是实验设计的一等目标。

**描述长度阶梯（什么才是真正可计算的）：**

Kolmogorov 复杂度 `K(x)` 在一般情况下不可计算（Chaitin）。实用的替代品，按「严谨性 vs 规模」排序：

1. **MDL / 符号回归复杂度** —— `L = L(data|program) + L(program)`，这正是 PySR 与符号回归已经在最小化的东西。*首要替身。*
2. **gzip / 归一化压缩距离** —— K 的一个粗略下界，O(n)，可扩展。*工程默认。*
3. **CTM / BDM** —— 对短（≤ ~12 比特）块近乎精确的算法概率；能捕捉压缩器漏掉的结构（如 `101010…`）。*用于玩具 DSL。*
4. **Lean/Coq 证明项** —— 在依赖类型证明助手中，证明项同时是程序、验证器（类型检查器）与描述长度对象（证明长度）。*最干净的实例化，但局限于形式化领域。*

## 10. 有效域：不同领域里「现实」是什么

本框架的有效域，由「是否存在某个可观测的、从现实采样的结果变量」所界定。「可验证性」是*命题形式*的性质，而非领域的性质——一个开放域的能力通常可以被重述为「带有现实结果变量的预测任务」。

| 领域 | 铁砧检查什么 |
|---|---|
| 代码 | 针对保留单元测试的执行 |
| 数学 | 答案抽取 / 形式化证明检查（Lean、Isabelle） |
| 物理 / 博弈 / 数据库 | 模拟器或确定性结果 |
| **开放域**（写作、对话、品味） | 一个*预测程序*——如「预测人类给哪段文字打分更高的程序」——针对保留的**人类判断**（外部样本）测试 |

开放域的两个诚实提醒：

1. **Goodhart 漂移。** 优化一个代理程序（预测的参与度）可能偏离真实质量，而该漂移通过*结果变量的选择*重新进入循环。这是真实且未解的边界。
2. **零结果域。** 对一个*没有*可观测结果的领域（私密的、未表露的品味），不存在外部接地——而且没有任何框架（包括人类实践）能可靠地在它上面自我改进。

## 11. 诚实的边界

**已接地**（有引用或定理）：
- 坍缩逃生逻辑：极小程序定义完整分布。
- 执行即外部接地（α > 0 项）。
- MDL/gzip/CTM/BDM 排序阶梯。
- 合成-vs-裁判的容错不对称性。
- 反循环不变量（验证器 ≠ LLM）。

**推测**（若你基于此继续，请标注 `[speculation]`）：
1. CTM/BDM 排序能否超越小程序规模。
2. 晶体是否构成*真正的*功能自我模型，而非外部化记忆——2607.04277 的声称**尚未被本设计证明**。
3. 循环在超过一两轮后是否真能复利——这正是实验设计中的消融 D 要解决的问题。
4. 开放域中的 Goodhart 漂移边界是否可解。

**未声称**：本框架目前已在任何地方*实现*；它*足以*实现 AGI；在路线图的安全审查之前它是*安全*的。
